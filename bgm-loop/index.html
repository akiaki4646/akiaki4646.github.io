bgm-loop

bgm-loop は、運営者が自分のYouTubeチャンネル(作業用BGM)を運営するために個人で使っている制作支援ツールです。一般公開・配布はしていません。

できること

  • 運営者自身のチャンネルの再生数・平均視聴時間などの統計を YouTube Analytics API で読み取る
  • YouTube Data API で公開動画を検索し、作業用BGMジャンルの傾向を集計する

動画のアップロード・編集・削除、コメント投稿など、書き込み操作は一切行いません(読み取り専用の権限のみ使用)。
